A premium, professional multi-page portfolio website for **Munaam Farooqui** — Web Developer & PHP Developer, built with a Royal Gold dark theme and smooth animations.

| Page | Description |
| --- | --- |

| Education | BS CCIS (SSUET), Aptech, Intermediate & Matriculation timeline |

## ✨ Features

- Royal Gold dark theme (custom palette)
- Responsive design (mobile / tablet / desktop)
- Preloader, custom cursor, scroll-reveal animations
- Particles hero, typewriter effect, animated skill bars
- Project cards with 3D tilt + lightbox gallery
- Contact form powered by Formspree (messages delivered to email)
- Floating WhatsApp chat button
- Downloadable CV (PDF)

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom theme + responsive breakpoints)
- JavaScript (vanilla, animations & interactions)
- Formspree (form backend)
- GitHub Pages (hosting)

## 🚀 Run Locally

Clone the repo and open `index.html` in a browser, or serve it locally:

```bash
git clone https://github.com/Munaam19/portfolio-v2.git
cd portfolio-v2
python -m http.server 8000
```

Then open `http://localhost:8000`.
